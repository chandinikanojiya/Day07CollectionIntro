# 🚀 Kotlin Collections Exploration

A beginner-friendly Kotlin project that demonstrates how to work with multiple values using **Collections (Data Structures)**. This project explores the foundational collection types in Kotlin, showcasing their features, use cases, and syntax through a hands-on exploration of our Solar System!

## 📌 What is Covered?

This project covers the four fundamental collection types in Kotlin:

* **Arrays (`arrayOf`)**
  * Fixed-size sequential collections.
  * Fast random access using zero-based indexing.
  * Demonstrates merging arrays and modifying elements.

* **Lists (`listOf` / `mutableListOf`)**
  * Ordered, dynamically resizable collections.
  * Iterating through elements using `for` loops.
  * Checking element existence using `contains()` and the `in` operator.
  * Adding, updating, and removing elements dynamically.

* **Sets (`mutableSetOf`)**
  * Unordered collections that strictly enforce **uniqueness** (no duplicate values).
  * Uses `hashCode()` behind the scenes for lightning-fast lookups in large data sets.

* **Maps (`mutableMapOf`)**
  * Collections based on **Key-Value pairs** linked via the `to` operator.
  * Unique keys mapped to non-unique values (e.g., tracking the number of moons for each planet).
  * Safe data retrieval using subscript syntax and handling `null` values.

## 🛠️ Prerequisites & Tools

* **Language:** Kotlin
* **Environment:** Run using Kotlin Playground or any standard Kotlin IDE (IntelliJ IDEA / Android Studio).
* **Concepts Utilized:** Object-Oriented Programming, Type Inference, and Generics.
